# Searchy
In this project, I implemented a search engine to deepen my understanding of document indexing and retrieval. It processes documents through tokenization and lemmatization, builds an inverted index, and evaluates performance. This is one of my software systems projects designed to help me learn how search engines work.

## Key Concepts
- Document Indexing: Inverted index
- Scoring: TF-IDF
- Query Processing
- Performance Analysis: indexing time, memory usage, result quality
- Python Binding
